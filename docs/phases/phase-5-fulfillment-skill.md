## Step 5.1: Fulfillment Agent System Prompt

```
你是租车平台的履约顾问。你的职责是帮助用户了解取还车、违章、续租等履约规则。

工作流程：
1. 了解问题：识别用户关心的履约场景
2. 查询规则：从知识库中检索对应规则
3. 补充上下文：如涉及具体订单，调用工具查询订单详情
4. 清晰解答：用简洁的语言解释规则和流程

约束：
- 履约规则以知识库为准，不得凭记忆编造
- 涉及具体订单的问题（如"我的订单能续租吗"），必须先查订单
- 不同供应商的规则可能不同，以知识库记录为准
- 紧急情况（事故、故障）应优先给出应急指引
```

## Step 5.2: 履约规则知识库

**目录**: `knowledge/fulfillment/`

### knowledge/fulfillment/pickup_rules.md
```markdown
## 取车规则

### 证件要求
- 国内用户：身份证 + 驾驶证（有效期剩余 3 个月以上）
- 外籍用户：护照 + 国际驾照/中国驾照
- 所有驾驶员必须实名登记

### 取车流程
1. 到达门店 → 出示证件 → 验证身份
2. 工作人员验车 → 确认车辆状况 → 签署验车单
3. 支付押金/预授权 → 取车

### 取车时间
- 建议提前 15 分钟到店
- 超过预约时间 2 小时未取车，订单可能自动取消
- 如需延时取车，请提前联系门店
```

### knowledge/fulfillment/return_rules.md
```markdown
## 还车规则

### 还车流程
1. 到达还车门店 → 工作人员验车
2. 确认车辆无新增损伤 → 签署还车单
3. 押金进入解冻流程

### 还车注意事项
- 必须在约定时间内还车，超时按额外时段计费
- 加满油还车（燃油车），否则需补加油费+服务费
- 还车时需保持车辆清洁，严重脏污可能收取清洁费

### 异地还车
- 支持部分城市异地还车，需支付异地还车费
- 费用 = 异地还车服务费 + 单程差价（如适用）
- 需在下单时选择异地还车选项
```

### knowledge/fulfillment/violation_rules.md
```markdown
## 违章处理规则

### 违章查询
- 还车后 30 天为违章观察期
- 平台会查询车辆违章记录
- 如有违章，客服会联系驾驶员处理

### 违章处理方式
1. 自行处理：收到通知后 15 个工作日内到交管部门处理
2. 平台代办：授权平台代办，需支付代办服务费
3. 押金扣除：逾期未处理，从押金中扣除违章罚款+服务费

### 违章费用
- 罚款金额：以交管部门实际罚单为准
- 代办服务费：100 元/次
- 逾期滞纳金：如产生，由驾驶员承担
```

### knowledge/fulfillment/extension_rules.md
```markdown
## 续租规则

### 续租条件
- 当前订单未到期
- 车辆在续租期间可被预约（无冲突）
- 续租起始日 = 当前到期日

### 续租方式
1. APP 自助续租：订单详情页点击"续租"
2. 客服续租：拨打平台客服电话
3. 门店续租：到店办理

### 续租费用
- 续租日租金 ≤ 原订单日租金（取低）
- 续租需补交续租期间保险费
- 续租无需重新支付押金
```

### knowledge/fulfillment/accident_guide.md
```markdown
## 事故/故障应急指引

### 发生事故
1. 确保人身安全，拨打 122 报警
2. 拍照保留现场证据（全景、碰撞部位、对方车牌）
3. 联系平台客服报案：400-xxx-xxxx
4. 获取交警事故认定书
5. 按保险流程理赔

### 车辆故障
1. 安全靠边停车，开启双闪
2. 联系平台客服：400-xxx-xxxx
3. 平台安排救援或换车
4. 因车辆本身故障导致的损失由平台承担

### ⚠️ 紧急情况优先级
1. 人身安全 > 财产保护 > 保险理赔
2. 不要离开事故现场
3. 不要私下和解（影响保险理赔）
```
